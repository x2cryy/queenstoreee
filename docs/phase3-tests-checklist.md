# اختبارات المرحلة الثالثة — ما ينفَّذ أين

## في قاعدة البيانات (ملف 004، تقرير PASS/FAIL)
منع الزبون من تعديل الحالة والدور، منع ترقية النفس، فصل الصلاحيات (واحدة لا تمنح غيرها)،
المدير لا يمنح نفسه ولا يرى بيانات خارج صلاحياته، المالكة وحدها تدير المديرين، لا مالكة ثانية عبر الـ API.

## في التطبيق (يدوياً، وأخبرني بالنتيجة)
1. /register بحساب تجريبي، يصلك بريد التأكيد، افتح الرابط.
2. /login ثم /account، ثم تسجيل الخروج.
3. /forgot-password ثم الرابط ثم /reset-password، ثم الدخول بالكلمة الجديدة.
4. /account/profile: غيّر الاسم والهاتف وتأكد من الحفظ بعد تحديث الصفحة.
5. افتح /account بلا تسجيل دخول: يجب التحويل إلى /login. افتح / وصفحات المنتجات: يجب أن تعمل بلا حساب.
6. احذف كوكيز الجلسة أثناء وجودك في /account وأعد التحميل: يجب أن تظهر صفحة انتهاء الجلسة.
7. من أدوات المتصفح: ابحث عن service_role في ملفات JavaScript المحمّلة (يجب ألا يوجد).
8. شغّل: npx tsc --noEmit و npm run build والصق لي أي خطأ.
